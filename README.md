# GOAT OS

GOAT OS is a web-based personal operating system built using HTML, CSS, and JavaScript. It simulates a desktop environment inside the browser, allowing users to interact with apps, windows, and system features similar to a real operating system.

## Overview

GOAT OS is designed as a creative project to explore how operating systems work at a basic level. It provides a graphical interface with draggable windows, a dock system, and multiple functional applications.

This project demonstrates frontend development skills, UI/UX design, and basic system logic.
