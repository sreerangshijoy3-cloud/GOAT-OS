# GOAT OS 2.O

GOAT OS is a web-based personal operating system built using HTML, CSS, and JavaScript. It simulates a desktop environment inside the browser.

## Overview

GOAT OS is designed as a creative project to explore how operating systems work at a basic level. 
This project demonstrates frontend development skills, UI/UX design, and basic system logic.
This is my first step for building my own os

### What's inside?

Hit `Enter` on the lock screen to boot into the desktop. Once you're in, you get a clean workspace with a top menu bar, a live clock, a right-click context menu, and a dock loaded with a bunch of mini-apps:

* **Notes** – A quick scratchpad for jotting down thoughts.
* **Browser** – Simple search launcher (opens results in a new tab).
* **Terminal** – A simulated command-line interface.
* **Calculator** – Basic arithmetic right on your desktop.
* **Files** – A mock file manager with a small image gallery.
* **Calendar** – Monthly view to check dates.
* **Music** – Built-in audio player with track selection and playback controls.
* **Weather** – Local weather widget (currently repping Kerala ☀️).
* **Stopwatch** – Simple timer for tracking seconds.
* **Settings** – Switch up your wallpapers, toggle between light/dark themes, and check system info.
