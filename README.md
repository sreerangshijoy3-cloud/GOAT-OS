# GOAT OS 2.O

GOAT OS is a web-simulation of a personal operating system built using HTML, CSS, and JavaScript. It simulates a desktop environment inside the browser.

## Overview

* In this simulation you can handle like linux.
* It have an inbuilt terminal.
* you can note something on it.
* also you can search with google
* inbuilt calculator
* files, calander, musics, etc...
